# Omar Clinical Device Observation Implementation Guide

This implementation guide defines standardized FHIR profiles for clinical observations generated by medical devices.

## Scope

The guide focuses on:

* Device-generated vital sign observations
* Consistent representation of measurement data
* Interoperability between clinical systems and devices

## Intended Audience

* Clinical system integrators
* Medical device manufacturers
* Health IT developers working with FHIR
